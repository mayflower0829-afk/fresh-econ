# 生鲜账 · 农产品电商单位经济计算器

生鲜农产品电商最痛的问题：**损耗、包装、冷链、佣金、包赔层层扒皮之后，卖一单到底赚不赚钱？** 本工具把这本账做成实时交互计算：输入采购与履约参数，立即得到每单损益瀑布、保本客单价、保本日均单量与参数敏感性（龙卷风图）。

**在线使用**：<https://cloud1-d4gsgj705497df85d-1501559031.tcloudbaseapp.com/freshecon/>

## 口径说明

- 损耗由卖家承担：客户收到足称重量，实际采购量为 `每单重量 ÷ (1 − 损耗率)`
- 售后包赔按客单价比例计提；平台佣金/支付费率按客单价计提
- 保本客单价 = 变动成本合计；保本日均单量 = 月固定成本 ÷ 30 ÷ 单均贡献毛利
- 龙卷风图：对损耗率、快递费、客单价、推广费、日均单量各做 ±10% 扰动，观察月利润变化幅度

## 预设方案

- **土拨购乡橙（5 斤装 99 元）**：来自三创赛国家级一等奖项目「启子智选·土拨购乡橙」（累计销售额约 16.6 万元）的经营口径，参数为演示用估计值
- **通用生鲜（客单 50 元）**：常见客单 30-50 元的生鲜档口口径

所有参数均可修改，计算纯前端实时完成。

## 局限

未覆盖平台活动补贴、退换货运费双程、发票税点、库存资金占用与多 SKU 混装；月利润为线性外推，未含季节性波动。欢迎按自己的类目补充参数。
